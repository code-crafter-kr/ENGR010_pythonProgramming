# ENGR010: Applied Engineering Computer Methods

## Introduction

ENGR010, "Applied Engineering Computer Methods," a course taken in Spring 2023. This course is an introduction to programming for engineering tasks, focusing on the use of programming tools to solve engineering problems. It includes interfacing sensors and actuators to a microcontroller board and programming it to interact with the real world, all within a computer lab setting.

## Course Objectives

- Understand the fundamentals of programming(Python) in the context of engineering.
- Learn to interface with hardware such as sensors and actuators using a microcontroller board.
- Apply programming skills to solve real-world engineering problems.
- Complete a final project that controls engineering equipment, demonstrating the application of learned skills.
